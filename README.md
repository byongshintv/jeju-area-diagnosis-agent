# 제주 동네 상권 진단 Agent

> **GitHub 소스판 안내** — 이 저장소는 대회 제출 ZIP에서 동봉 Python(`python\`)과 심사용 `.env`(평가용 AI 키)를 뺀 소스입니다. 나머지 코드·데이터·문서는 ZIP과 같습니다.
> - 실행: Python 3.13을 설치한 뒤 이 폴더에서 `python -m jeju_agent`(외부 패키지 없음). 브라우저에서 `http://127.0.0.1:8765/`을 엽니다. `실행.bat`는 ZIP의 동봉 Python 전용입니다.
> - AI 모드: `.env.example`을 `.env`로 복사해 `LLM_BASE_URL`·`LLM_API_KEY`·`LLM_MODEL`을 채웁니다. 비우면 규칙 모드로 모든 기능이 동작합니다.
> - 테스트: `python -m unittest discover -s tests -t .`

센터 PC에서 "노형동에서 카페 창업하면 어때?"라고 물으면, 이 PC 안에서 도는 AI Agent가 제주데이터허브·제주빅데이터센터 데이터를 골라 계산합니다. 그 동네가 제주 43개 읍면동 가운데 어디쯤인지 순위 눈금과 지도로 보여 주고, 센터 데이터로 만든 표는 반출 기준(10 미만 값·역산)에 걸릴 칸을 미리 가립니다.

- 실행: Windows 10·11, 설치 없이 `실행.bat` 더블클릭
- 필요한 것: 없음. Python이 동봉돼 있고 외부 패키지를 쓰지 않습니다(표준 라이브러리만).
- 인터넷: 없어도 됩니다. 동봉 허브 스냅샷과 규칙 모드로 모든 기능이 동작합니다. AI 모드와 허브 데이터 재수집에만 인터넷이 필요합니다.

## 1. 빠른 시작(3단계)

1. ZIP 파일을 원하는 폴더에 풉니다(예: `C:\제주상권진단`). 압축을 푼 뒤 실행하세요. ZIP 안에서 바로 실행하면 동작하지 않습니다.
2. `실행.bat`를 더블클릭합니다. 검은 창이 뜨고 잠시 뒤 브라우저(Chrome·Edge)에 `http://127.0.0.1:8765/`이 열립니다.
3. 예시 질문을 누르거나, 질문 칸에 "노형동에서 카페 창업하면 어때?"를 입력하고 **묻기**를 누릅니다.

- 검은 창은 프로그램 본체입니다. 쓰는 동안 닫지 마세요. 끝낼 때 창을 닫거나 `Ctrl+C`를 누르면 됩니다.
- 브라우저가 열리지 않으면 주소창에 `http://127.0.0.1:8765/`을 직접 입력합니다.
- `실행.bat`를 다시 누르면 새로 띄우지 않고 이미 열린 화면으로 보냅니다.

자세한 화면 사용법·키 설정·문제 해결은 `문서/1_사용자_매뉴얼`에 있습니다.

## 3. 설치·실행 절차

설치 프로그램이 없습니다. 압축을 풀고 `실행.bat`를 실행하는 것이 설치입니다.

`실행.bat`가 하는 일은 아래 한 줄과 같습니다. 명령 창에서 직접 실행해도 됩니다.

```
python\python.exe -m jeju_agent
```

옵션: `--port 8800`(포트 변경), `--no-browser`(브라우저 자동 열기 끔), `--help`.

이미 Python 3.10 이상이 설치된 PC나 Linux·macOS에서는 동봉 Python 없이 폴더에서 `python -m jeju_agent`로 실행할 수 있습니다.

## 5. 환경변수(.env)

`.env.example`을 같은 폴더에 `.env`로 복사해 필요한 값만 채웁니다. 비어 있으면 규칙 모드(AI 없이)로 동작합니다. 같은 이름의 Windows 환경변수가 있으면 `.env`보다 우선합니다.

| 이름 | 기본값 | 설명 |
|---|---|---|
| `HOST` | `127.0.0.1` | 접속 주소. 이 PC 안에서만 열립니다 |
| `PORT` | `8765` | 포트. 다른 프로그램이 쓰고 있으면 바꿉니다 |
| `OPEN_BROWSER` | `true` | 시작할 때 브라우저 열기(`실행.bat`는 항상 켬) |
| `RUNTIME_DIR` | (빈칸=`runtime\`) | 로그·업로드 임시 폴더 |
| `LLM_BASE_URL` | (빈칸) | AI 모드 공급자 주소. 예: `https://api.openai.com/v1` |
| `LLM_API_KEY` | (빈칸) | AI 모드 API 키. 비우면 규칙 모드 |
| `LLM_MODEL` | (빈칸) | 모델 이름. 도구 호출(tool calling)을 지원하는 모델 |
| `HUB_API_KEY` | (빈칸) | 제주데이터허브 프로젝트 키. 허브 재수집 때만 사용 |
| `HUB_BASE_URL` | `https://open.jejudatahub.net/api/proxy/` | 허브 Open API 주소 |
| `CENTER_TO_LLM` | `off` | `off`: 센터 데이터 값은 AI 모델로 보내지 않음. `aggregates`: 반출 점검을 통과한 집계값만 보냄 |

이 ZIP의 `.env`에는 심사용 AI 키가 들어 있어 `실행.bat`만으로 AI 모드가 켜집니다(River, `deepseek-ai/DeepSeek-V4.1-Flash`, 결제수단 없는 가입 크레딧 키, 평가 후 폐기). 허브 키는 들어 있지 않습니다. 발급·설정 방법은 사용자 매뉴얼 5·6절에 있습니다.

## 8. 오류·제약사항

| 상황 | 원인·대처 |
|---|---|
| 검은 창에 "포트 8765을(를) 열 수 없습니다" | 다른 프로그램이 같은 포트를 씁니다. `.env`의 `PORT`를 `8766` 등으로 바꿉니다 |
| Windows가 "PC 보호" 창을 띄움 | 인터넷에서 받은 bat 파일이라 뜨는 경고입니다. **추가 정보 → 실행**을 누릅니다 |
| 화면 위에 "규칙 모드 (AI 키 없음)" | AI 키가 없거나 비어 있습니다. 규칙 모드로 모든 기능이 동작합니다 |
| "LLM을 사용할 수 없어 규칙 모드로 답했습니다" 안내 | AI 호출 오류·시간 초과·빈 응답입니다. 괄호 안에 사유가 표시됩니다 |
| 센터 CSV를 올렸는데 "명세(70개 시트)와 일치하는 헤더를 찾지 못했습니다" | 1행 열 이름이 센터 명세와 다른 파일입니다. 센터에서 받은 결과 CSV를 고치지 말고 그대로 올립니다 |

데이터 해석의 제약:

- 유동인구 지수는 허브 문서에 집계 단위 설명이 없어 사람 수로 말하지 않고 상대 비교로만 씁니다.
- 유동인구는 각 달 1~3일, 버스는 각 달 1일 표본입니다. 월 전체 평균이 아닙니다.
- 카드·POS 자료는 카드·표본 점포 기준이라 현금 거래가 빠져 있습니다. 임대료·인건비는 분석에 들어 있지 않습니다.
- 시간대·요일 비중은 센터 자료가 없으면 제주 전체 값(허브)을 씁니다. 화면에 "우리 지역 구분 없음"으로 표시합니다.
- 점포당 카드 이용금액은 분자(2020년)와 분모(2025-09) 시점이 달라 참고값입니다.
- 반출 사전 점검은 대회 게시판 답변의 기준을 따른 **사전** 점검입니다. 최종 반출 판정은 제주빅데이터센터 심사입니다.
- 동봉 센터 데이터는 형식 시연용 가상 예시입니다. 화면·보고서에 "가상 예시"로 표시됩니다.
- 허브 스냅샷은 고정 사본입니다. 최신 자료가 필요하면 매뉴얼 6절대로 다시 받습니다.
