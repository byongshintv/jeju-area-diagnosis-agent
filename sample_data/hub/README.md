# 허브 스냅샷 (sample_data/hub)

`tools/fetch_hub_snapshots.py`가 제주데이터허브 **공개** 데이터를 받아 저장한 고정 사본입니다.
각 CSV 옆의 `*.meta.json`에 출처 데이터 ID·기간·행수·이용조건·컬럼이 들어 있습니다.
키 값은 어디에도 저장하지 않습니다.

## 요청 데이터와 실제 대체

|---|---|---|---|---|
| floating_pop_emd(hub:583) | 유동인구 지수(허브 집계값) | 2025-09 ~ 2026-08 | 8256 | 요청 753(읍면동 내국인 유동인구)을 Open API 583으로 직접 받아 월 일평균으로 집계 |

## 다시 받기

```
python3 tools/fetch_hub_snapshots.py
```

유동인구 지수(허브 집계값): 단위 미공개, 상대 비교만 사용. 허브 583 상세 메타와 첨부 API 가이드(인구읍면동단위내국인유동인구API.hwp, file id 1096)를 확인했으나 집계 단위 설명이 없음.
